auditor-v1 / websec

Red Team · Auditoría Web

Auditor de seguridad web en Python: SSL/TLS, cabeceras de seguridad, XSS, SQLi, CORS, SSRF y enumeración de subdominios. Genera un reporte PDF automático con puntuación CVSS, con arquitectura modular lista para integrarse en pipelines de seguridad.
